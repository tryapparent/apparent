# Record capture request

This headless TypeScript owner coordinates one opaque request ID from admission
through its native saved receipt. It owns lifecycle sequencing and status
projection; Desktop supplies the same-user native CLI, durable replay journal,
Electron runtime and plugin mailbox. Native capture admission remains
authoritative for permissions, active work and resource safety.

Run `npm ci`, `npm run typecheck`, `npm run build` and `npm test` here with Node
22.18+. The package has no Electron, Rust, UI or OS dependencies. It never
retries a start, stops or cancels an admitted capture, sends a handoff, or
chooses a destination.
