# Independent Engine inputs

`consumers.ts` omits only `engine-media` for the finite Desktop executor and
runner regression inventory in `qualify.ts`. All other owners, Desktop native
verification, signing and packaging consumers remain selected. This is not a
native-proof exemption for the application or independently published Engine.

Engine's producer copies `engine/native/` outside the checkout and builds with
its own Cargo manifest/lockfile; its SDK is packed from `engine/sdk/`. The copied
qualification programs are `engine/tools/qualify.ts` and `qualify-frames.ts`.
`stream-engine.yml` supplies compiler, runner, FFmpeg/GStreamer and Ubuntu action
inputs. None executes the audited Desktop executor family. Engine selection and
publication do consume shared selector/admission code; those inputs stay broad.

The range guard inspects both committed trees, regular modification status,
reviewed static module edges, unchanged literal builtin loaders, and inbound
filesystem/module references. Unknown references, aliases, new imports, added or
deleted files and mode changes revoke the exception. New files (including the
separately owned Mac pill regression) retain conservative routing. Extend this
finite inventory only after auditing the real producer and consumers. Removing
the classification restores the original fanout.

Both shared/Engine CLIs, local hook command selection and publication continuation
are exercised against real source blobs committed into isolated Git fixtures.
`currentStream` consumes the guarded range decision, so an unsafe input cannot
become a publication exemption through path-only reclassification. Tests retain
Engine selection for source, SDK, qualifier, workflow, toolchain/action, shared
routing, unknown and mixed changes. Frozen sibling qualifier/CLI patches require
compatibility checks independently of this inventory.

Selection proof is not a measured recurring speedup or native acceptance.
Natural hosted runs remain necessary; this routing implementation itself changes
shared execution inputs and legitimately requires every Engine lane.
