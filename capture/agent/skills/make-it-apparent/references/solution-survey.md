# Agent-made change walkthroughs: source survey

Primary-source survey for the `make-it-apparent` procedure. These are patterns to borrow, not dependencies to install. Accessed 2026-10-28. A project accepting recordings is not proof that its agents routinely produce them.

| Source | What it actually offers | Useful lesson / limit |
| --- | --- | --- |
| [OpenClaw `proof-video` developer skill](https://github.com/openclaw/openclaw/blob/main/.agents/skills/proof-video/SKILL.md) and [PR media reference](https://github.com/openclaw/openclaw/blob/main/.agents/skills/openclaw-pr-maintainer/references/media.md) | Repo-local Playwright helper records a **mocked** Control UI, cue sidecar timestamps captions/zoom/speed, ffmpeg produces a caption-burned H.264 MP4; native video can use hand-written cues. Raw proof is retained; final media inspected before attachment. | Keep source and share copy distinct. Burn captions for players that ignore subtitle tracks; check cue sync and transitions. Mocked UI proves only mocked behavior. Its helper is OpenClaw-specific, not a portable Apparent command. |
| [OpenCode PR template](https://github.com/anomalyco/opencode/blob/dev/.github/pull_request_template.md), [example UI PR](https://github.com/anomalyco/opencode/pull/17520), [example skill UI PR](https://github.com/anomalyco/opencode/pull/28239) | Template asks for a screenshot **or** recording for UI changes, plus a statement of local verification. Examples attach `.mov` screen recordings and describe tested environments. | Pair footage with an explicit verification claim. No official OpenCode agent-video production skill was established by this survey; do not attribute one to the team. |
| [Microsoft Playwright CLI video recording reference](https://github.com/microsoft/playwright/blob/main/packages/playwright-core/src/tools/skills/playwright-cli/references/video-recording.md) | Browser screencast with cursor, action markers, chapter overlays; recommends rehearsing with locators, then recording a focused hero script and attaching the result. | A good browser-only fallback when that installed CLI exposes these commands. It does **not** record native windows. Do not silently assume a local Playwright version has the same API. |
| [DemoForge skill](https://github.com/DixitRam/Demo-Forge/blob/main/.claude/skills/demoforge/SKILL.md) | Scripted `flow.json`: off-camera setup, 4–8 actions, narration per beat, frame review, editor for final cut; user chooses metered voice/export. | Rehearse a small goal-driven flow, inspect every meaningful state, say why rather than read labels. Full editor/TTS pipeline is too much for a quick change proof. |
| [ProofShot README](https://github.com/AmElmo/proofshot/blob/main/README.md) | Agent-agnostic browser verification sessions bundle video, screenshots, action timeline, browser/server errors and local viewer; optional PR upload. The vendor's compatibility claim does not make this an OpenCode-maintained skill, and its browser-only capture cannot prove native behavior. |
| [Evidence-Driven Testing skill](https://github.com/michaelshimeles/skills/blob/main/evidence-driven-testing/SKILL.md) | Live GUI test recording with timestamped assertions, explicit revision/environment, crash-safe capture and headless fallback. | Record the action being tested rather than a replay of an already-successful state; mark untested claims. Do not import its larger recorder or PR-posting machinery into a lightweight skill. |
| [Community `demo-video` OpenClaw skill listing](https://github.com/sundial-org/awesome-openclaw-skills/blob/main/skills/demo-video/SKILL.md), [OpenMontage Playwright recording skill](https://github.com/calesthio/openmontage/blob/HEAD/.claude/skills/playwright-recording/SKILL.md) | CDP frame capture + ffmpeg and basic Playwright context video, respectively. | Capture mechanics are useful, but fixed sleeps and generic scripts alone do not establish the result or privacy. The community listing is **not** the official OpenClaw project's skill. |

## Synthesis for Apparent

Keep the native product's short path: one question, visible before/action/after, installed-Apparent capture, source bundle inspection, and a playable share copy. Borrow OpenClaw's raw/edited distinction and caption synchronization only when an edit is justified; DemoForge's rehearsal and frame check; OpenCode's verification statement; and ProofShot's pairing of video with state/error evidence. Do not turn every code change into a marketing production or introduce mandatory Playwright, TTS, ffmpeg, or uploads. Never treat a simulated flow, different host, or browser replay as evidence of the named native build.
