# Pitch deck skills

Start with [Pitch Deck From Scratch](pitch-deck-from-scratch/SKILL.md) for the full workflow, from the brand brief and investor story to an editable deck and an Apparent feedback pass.

For individual steps:

- [Brand Guidelines Questionnaire](brand-guidelines-questionnaire/SKILL.md) turns answers and visual references into a one-page guide.
- [Pitch Deck Outline](pitch-deck-outline/SKILL.md) plans a 10–12 slide investor story.
- [Document Slide Design Process](document-slide-design-process/SKILL.md) covers image-generated Crazy 8s, refinement, reconstruction, and rendered review.

These are repository resources. For a Git checkout, open the relevant `SKILL.md` or install its directory with your agent's skill installer. This folder is outside desktop and website packaging inputs and is marked `export-ignore` for source archives.
