Screen recordings your coding agent can read

Apparent is an open-source screen recorder for macOS and Linux. Record your screen, talk through a change, and draw on the part that matters. Paste the capture into Codex, Claude Code, or another coding agent.

Choose your setup

  • Record on your desktop

    Install Apparent and grant screen and microphone permissions when prompted. Press ⌥⇧S on macOS or Alt+Shift+S on Linux to start and stop, then paste into your agent chat.

    Download Apparent

  • Read a capture on an agent machine

    Install the Apparent CLI on the machine that will read the capture. The optional reading skill teaches the agent which frames to inspect and how to zoom in.

    • Install the headless CLI
    • Install the capture-reading skill
    • Read the skill instructions

  • Have your agent record a walkthrough

    Install the separate video-making skill for a narrated demo of a change. Live desktop recording requires a running app, capture permissions, and a safe screen to record.

    Install the video-making skill

What the agent receives

A .apparent bundle contains annotated keyframes, a timed transcript, and an interaction timeline. This example shows how the pieces fit together for a UI bug.

For a local bundle, run apparent inspect <bundle> to read the summary and apparent zoom <bundle> --at 0:08 to look closer. See the CLI guide.
