Screen recordings your coding agent can read

Apparent is an open-source screen recorder for macOS and Linux. Record your screen, talk through a change, and draw on the part that matters. Paste the capture into Codex, Claude Code, or another coding agent.

Choose your setup

  • Record on your desktop

    Install Apparent and grant screen and microphone permissions when prompted. Press ⌥⇧S on macOS or Alt+Shift+S on Linux to start and stop, then paste into your agent chat.

    Download Apparent

  • Read a capture on an agent machine

    Install the Apparent CLI on the machine that will read the capture. The optional reading skill teaches the agent which frames to inspect and how to zoom in.

    • Install the headless CLI
    • Install the capture-reading skill
    • Read the skill instructions

  • Have your agent record a walkthrough

    Install the separate video-making skill for a narrated demo of a change. Live desktop recording requires a running app, capture permissions, and a safe screen to record.

    Install the video-making skill

Send a screen recording to Claude Code or Codex

A marked screenshot can show which button needs to move. When a menu closes before you can click an item, record the pointer movement that triggers it. Say what you expected while you reproduce the bug.

Stop the capture and paste it into your agent chat. For a local capture, the agent needs access to the .apparent bundle and the Apparent CLI.

The pointer opens File actions and moves down toward Rename. The menu closes before the pointer gets there. The narrator says it should stay open until they reach Rename.

What the agent can inspect

Ask your agent to inspect the bundle and check the relevant moment. Substitute the path and timestamp from your recording.

apparent inspect ./menu-bug.apparent
apparent zoom ./menu-bug.apparent --at 0:20

The transcript renders “File actions” as “fellow action.” The zoom frames show the File actions label and the open Rename menu at 0:19.500. At 0:21.136 the pointer is below File actions and the menu is gone. The agent can use those frames to investigate what closes the menu. See the CLI guide.

Apparent and Tellscreen on the same screen recording

On November 26, 2026, we ran the 15-second Rename-menu clip above through both tools. We tested what each tool could give a coding agent from an existing video.

  • Apparent on Linux

    Apparent imported the video into a local .apparent bundle and transcribed the expected behavior. The frame sheet shows Rename at 0:06.863 and the closed menu at 0:07.045. The imported bundle has no separate click, ink, or window events.

    apparent import ./menu-demo.mp4 --out ./menu-import.apparent
apparent zoom ./menu-import.apparent --at 0:07

  • Tellscreen’s video converter

    The converter returned a Markdown handoff with four hosted screenshots. We opened images showing the menu before and after it closed. The transcript was empty in both attempts, using the original MP4 and the same video and audio in a MOV container. See Tellscreen’s handoff guide.
