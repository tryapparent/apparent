How to record your screen, talk, and point for Claude Code or Codex

Record the few seconds where the problem happens. Say what you expected while you point to the relevant control, then paste the capture into your coding agent’s chat. Apparent gives the agent a timed transcript and frames it can inspect at the same moment.

Record one change

  1. Install Apparent on macOS or a compatible Linux desktop and grant screen and microphone permissions when prompted. Check the Linux setup guide for compositor and input requirements.
  2. Press Option+Shift+S on macOS or Alt+Shift+S on Linux to start. Use your own shortcut if you changed it in Settings.
  3. Describe what you expected as you reproduce what happened. Point to the control and keep enough of the surrounding screen visible to identify it. Where supported, hold Shift to draw or Shift-click to drop a pin.
  4. Press the shortcut again to finish, then paste into your agent chat if Apparent hasn’t already done so. Check the draft and send it yourself.

Give the agent a moment to inspect

Check which parts of the paste arrived. Composer support varies, and the handoff can include a contact sheet, timed transcript, and interaction summary. The original recording and frames are in the .apparent bundle.

For a local handoff, give the agent access to the complete bundle and the Apparent CLI. If the agent runs on another machine, transfer the folder through an approved route and use the path on that machine. Attach the contact sheet directly when it gives the agent enough context.
