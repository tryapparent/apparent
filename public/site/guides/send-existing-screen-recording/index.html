How to send an existing screen recording to Claude Code or Codex

If you already have an MP4 or MOV screen recording, Apparent can import it into a local bundle with frames and a transcript. Your coding agent can inspect the moment you describe, even if you used another app to record it.

Import the video

Install the Apparent CLI on a supported Mac or Linux machine. Run these commands in the folder that contains the video and use your video’s filename.

apparent import ./screen-recording.mp4 --out ./ui-bug.apparent
apparent inspect ./ui-bug.apparent

inspect prints a summary and any transcribed speech. The bundle holds the recording and images. The pointer can be visible in the footage. Separate click, ink, and window events are available from supported native captures.

Keep the bundle directory together. If the agent runs on a different machine, transfer the complete folder through an approved route, then give the agent its path on that machine.

Tell the agent where to look

Inspect ./ui-bug.apparent around 0:07. Which item was I trying to select, and what changed before I got there? Explain what the frames show before suggesting a fix.

Use zoom to make a sheet of nearby frames. Use frames when you know the start and end of the sequence.

apparent zoom ./ui-bug.apparent --at 0:07
apparent frames --from 6.5 --to 8.5 --fps 6 ./ui-bug.apparent
